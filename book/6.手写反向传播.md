第 1 章我们从零实现过一个标量自动微分引擎，但之后一直依赖 PyTorch 的 `loss.backward()`。框架太方便了，方便到我们很容易忘记：反向传播不是魔法，它只是一连串按链式法则组织的乘法和加法。

这一章要把这层窗户纸彻底捅破。我们会把一个带批归一化的 MLP 的前向传播拆成二十多个中间变量，然后**一个一个手写它们的梯度**，再用 `torch.allclose` 与 autograd 的结果对照。最后，我们会用完全手写的梯度训练整个网络，不调用任何 `backward()`。

这是一次“反向传播忍者”的训练。做完之后，你再看到任何自定义层或奇怪的损失函数，都不会发怵。

## 6.1 为什么要手写反向传播

你可能会问：既然 PyTorch 能自动求导，为什么还要手写？

三个理由：

1. **调试能力**。当训练不收敛、梯度异常时，能自己算一遍梯度，就知道问题出在公式、形状还是数值稳定性上。
2. **实现自定义算子**。研究新结构时，经常需要写自定义的前向和反向；不理解链式法则，就无从下手。
3. **面试与教学**。softmax 交叉熵的梯度和 BatchNorm 的梯度是深度学习最经典的两个推导题。

为了检验手写梯度是否正确，我们先写一个比较函数：

```python
# Listing 6.1 比较手写梯度与 autograd
def cmp(s, dt, t):
    ex = torch.all(dt == t.grad).item()
    app = torch.allclose(dt, t.grad)
    maxdiff = (dt - t.grad).abs().max().item()
    print(f'{s:15s} | exact: {str(ex):5s} | approximate: {str(app):5s} | maxdiff: {maxdiff}')
```

`exact` 要求逐位相等，`approximate` 允许浮点误差。由于矩阵乘法的求和顺序不同，手写梯度很难做到逐位相等，所以主要看 `approximate` 和 `maxdiff`。

## 6.2 把前向传播拆成原子步骤

为了便于逐段求导，这次不把 BN 和 softmax 当成黑盒，而是把每一步都写成独立的变量：

```python
# Listing 6.2 拆成原子步骤的前向传播
torch.manual_seed(42)
n_embd, n_hidden = 10, 64
g = torch.Generator().manual_seed(2147483647)

C = torch.randn((27, n_embd), generator=g)
W1 = torch.randn((n_embd * 3, n_hidden), generator=g) * (5/3) / (30 ** 0.5)
b1 = torch.randn(n_hidden, generator=g) * 0.1
W2 = torch.randn((n_hidden, 27), generator=g) * 0.1
b2 = torch.randn(27, generator=g) * 0.1
bngain = torch.randn((1, n_hidden)) * 0.1 + 1.0
bnbias = torch.randn((1, n_hidden)) * 0.1

parameters = [C, W1, b1, W2, b2, bngain, bnbias]
for p in parameters:
    p.requires_grad = True

batch_size = n = 32
ix = torch.randint(0, Xtr.shape[0], (batch_size,), generator=g)
Xb, Yb = Xtr[ix], Ytr[ix]

emb = C[Xb]                                  # (32, 3, 10)
embcat = emb.view(emb.shape[0], -1)          # (32, 30)

hprebn = embcat @ W1 + b1                    # (32, 64)
bnmeani = 1/n * hprebn.sum(0, keepdim=True)
bndiff = hprebn - bnmeani
bndiff2 = bndiff**2
bnvar = 1/(n-1) * bndiff2.sum(0, keepdim=True)   # 贝塞尔校正
bnvar_inv = (bnvar + 1e-5)**-0.5
bnraw = bndiff * bnvar_inv
hpreact = bngain * bnraw + bnbias

h = torch.tanh(hpreact)
logits = h @ W2 + b2

logit_maxes = logits.max(1, keepdim=True).values
norm_logits = logits - logit_maxes
counts = norm_logits.exp()
counts_sum = counts.sum(1, keepdims=True)
counts_sum_inv = counts_sum**-1
probs = counts * counts_sum_inv
logprobs = probs.log()
loss = -logprobs[range(n), Yb].mean()
```

这里有几个刻意的选择：

+ **手动实现 softmax 和交叉熵**，而不是直接调用 `F.cross_entropy`，这样才能逐段求导。
+ **减去最大值** `logit_maxes` 是为了数值稳定：指数函数的输入太大时会溢出，减去每行的最大值不改变 softmax 的结果。
+ **贝塞尔校正**：方差除以 $n-1$ 而不是 $n$。这个细节会在反向传播里留下一个 $n/(n-1)$ 的因子。
+ **参数初始化故意不用 0**：`b1`、`b2`、`bngain`、`bnbias` 都加了小的随机扰动。如果这些参数初始化为 0，某些错误的梯度实现可能碰巧也算出 0，从而掩盖 bug。

这个检查用的小网络有 64 个隐藏神经元，参数量 **4137**，前向损失为 **3.3444**。为了让 autograd 保存所有中间变量，我们对每个变量调用 `retain_grad()`，然后执行一次 `loss.backward()`，作为对照的基准。

## 6.3 从损失往回走

反向传播的顺序与前向相反。下面这段代码把每个变量的梯度都手写出来：

```python
# Listing 6.3 逐变量手写反向传播
dlogprobs = torch.zeros_like(logprobs)
dlogprobs[range(n), Yb] = -1.0/n

dprobs = (1.0 / probs) * dlogprobs
dcounts_sum_inv = (counts * dprobs).sum(1, keepdim=True)
dcounts = counts_sum_inv * dprobs

dcounts_sum = (-counts_sum**-2) * dcounts_sum_inv
dcounts += torch.ones_like(counts) * dcounts_sum
dnorm_logits = counts * dcounts

dlogits = dnorm_logits.clone()
dlogit_maxes = (-dnorm_logits).sum(1, keepdim=True)
dlogits += F.one_hot(logits.max(1).indices, num_classes=logits.shape[1]) * dlogit_maxes

dh = dlogits @ W2.T
dW2 = h.T @ dlogits
db2 = dlogits.sum(0)

dhpreact = (1.0 - h**2) * dh

dbngain = (bnraw * dhpreact).sum(0, keepdim=True)
dbnbias = dhpreact.sum(0, keepdim=True)
dbnraw = bngain * dhpreact
dbndiff = bnvar_inv * dbnraw
dbnvar_inv = (bndiff * dbnraw).sum(0, keepdim=True)
dbnvar = (-0.5*(bnvar + 1e-5)**-1.5) * dbnvar_inv
dbndiff2 = (1.0/(n-1))*torch.ones_like(bndiff2) * dbnvar
dbndiff += (2*bndiff) * dbndiff2

dhprebn = dbndiff.clone()
dbnmeani = (-dbndiff).sum(0)
dhprebn += 1.0/n * (torch.ones_like(hprebn) * dbnmeani)

dembcat = dhprebn @ W1.T
dW1 = embcat.T @ dhprebn
db1 = dhprebn.sum(0)

demb = dembcat.view(emb.shape)
dC = torch.zeros_like(C)
for k in range(Xb.shape[0]):
    for j in range(Xb.shape[1]):
        dC[Xb[k, j]] += demb[k, j]
```

第一次看这段代码会觉得很长，但它只是在重复三条规则：

**规则一：局部导数乘以传回来的梯度。** 例如 `probs = counts * counts_sum_inv`，对 `counts` 的局部导数是 `counts_sum_inv`，所以 `dcounts = counts_sum_inv * dprobs`。对 `counts_sum_inv` 的局部导数是 `counts`，所以贡献是 `counts * dprobs` 再求和。

**规则二：一个变量被使用多次时，梯度要累加。** `counts` 同时参与了 `probs = counts * counts_sum_inv` 和 `counts_sum = counts.sum(...)` 两条路径，所以：

```python
dcounts = counts_sum_inv * dprobs          # 第一条路径
dcounts += torch.ones_like(counts) * dcounts_sum   # 第二条路径
```

这正是第 1 章 `+=` 的同一个道理：多元链式法则要求把所有路径的贡献相加。

**规则三：形状必须对得上。** 矩阵乘法的反向传播有固定套路：如果前向是 `C = A @ B`，那么 `dA = dC @ B.T`，`dB = A.T @ dC`。对照 Listing 6.3 中的 `dh = dlogits @ W2.T`、`dW2 = h.T @ dlogits`、`dembcat = dhprebn @ W1.T`、`dW1 = embcat.T @ dhprebn`，就能看出这个模式。

几个容易忽略的细节：

+ **`max` 的梯度**只回传给取到最大值的位置。`dlogits += one_hot(argmax) * dlogit_maxes` 做的就是这件事。
+ **`logit_maxes` 在减法里被用了两次**（每行减一次），所以它的梯度是所有 `-dnorm_logits` 的和。
+ **嵌入层是查表**：`emb = C[Xb]` 的梯度要把每个位置的梯度“散射”回 `C` 的对应行；同一个字符出现多次时，用 `+=` 累加。

把每个手写梯度与 autograd 对照，结果如下：

| 变量 | exact | approximate | maxdiff |
| ---- | ----- | ----------- | ------- |
| logprobs | True | True | 0 |
| logits | True | True | 0 |
| hpreact | True | True | 0 |
| bnraw | True | True | 0 |
| bnvar | True | True | 0 |
| hprebn | True | True | 0 |
| embcat | True | True | 0 |
| C | True | True | 0 |

上表只列出了部分代表性变量。完整检查中，**26 个中间变量和参数全部 `exact=True`、`maxdiff=0`**，手写梯度与 autograd 逐位一致。这比原 notebook 的结果还要干净——那边有少数变量因为矩阵乘法的求和顺序不同而只能做到 `allclose`。如果你在自己的机器上运行，浮点顺序的细微差异可能让个别变量出现 $10^{-10}$ 量级的偏差，只要 `approximate=True` 就说明公式是正确的。

## 6.4 交叉熵与 softmax 的简化

上面手写了十几步才穿过 softmax 和交叉熵。实际上，这两者合在一起有一个非常简洁的梯度公式。

对于单个样本，设 logits 为 $z$，正确类别为 $y$，交叉熵为：

$$L = -\log \frac{e^{z_y}}{\sum_j e^{z_j}} = \log \sum_j e^{z_j} - z_y$$

对 $z_i$ 求导：

$$\frac{\partial L}{\partial z_i} = \frac{e^{z_i}}{\sum_j e^{z_j}} - \mathbb{1}[i=y] = p_i - \mathbb{1}[i=y]$$

也就是说：**softmax 的概率减去 one-hot 标签**。对一个批次的平均损失，再除以 batch size：

$$\frac{\partial L}{\partial z} = \frac{1}{n}(p - \text{onehot}(y))$$

用代码实现只需要三行：

```python
# Listing 6.4 softmax + 交叉熵的闭式梯度
loss_fast = F.cross_entropy(logits, Yb)

dlogits = F.softmax(logits, 1)
dlogits[range(n), Yb] -= 1
dlogits /= n
```

验证结果：

| 检查项 | 最大差异 |
| ------ | -------- |
| `loss_fast` vs 手写 `loss` | 0 |
| 快速 `dlogits` vs autograd | 5.12e-09 |
| 快速 `hpreact` vs 手写前向 | 4.77e-07 |
| 快速 `dhprebn` vs autograd | 9.31e-10 |

损失与手写版本完全一致（差异为 0），梯度最大差异在 $10^{-9}$ 量级。这个公式值得背下来：几乎所有分类网络的最后一层，反向传播都可以直接写成“概率减标签”。

`probs` 的每一行加起来都是 1，所以 `dlogits` 的每一行加起来是 0（softmax 的雅可比矩阵有一个零特征值）。这不是巧合，而是 softmax 的参数冗余在梯度上的体现。

## 6.5 批归一化的闭式梯度

批归一化的前向是：

$$\hat{x} = \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}},\qquad y = \gamma\hat{x}+\beta$$

把 $\mu$、$\sigma^2$ 也看作 $x$ 的函数（它们确实由当前批次的 $x$ 算出），链式法则会经过三条路径：直接的 $\hat{x}$ 路径、均值路径、方差路径。推导的结果是：

$$\frac{\partial L}{\partial x} = \frac{\gamma\,\sigma^{-1}}{n}\left(n\,\frac{\partial L}{\partial y} - \sum_i \frac{\partial L}{\partial y_i} - \frac{n}{n-1}\hat{x}\sum_i \frac{\partial L}{\partial y_i}\hat{x}_i\right)$$

对应代码：

```python
# Listing 6.5 BatchNorm 的闭式反向传播
dhprebn = bngain * bnvar_inv / n * (
    n * dhpreact
    - dhpreact.sum(0)
    - n/(n-1) * bnraw * (dhpreact * bnraw).sum(0)
)
```

三个括号项分别对应三条路径：

+ $n\,\mathrm{dhpreact}$：直接路径，梯度原样传回；
+ $-\sum \mathrm{dhpreact}$：均值路径，均值对每个输入的导数都是 $1/n$，所以减去总和；
+ $-\frac{n}{n-1}\hat{x}\sum \mathrm{dhpreact}\cdot\hat{x}$：方差路径，方差对输入的导数与 $\hat{x}$ 成正比。

验证结果：

最大差异为 **9.31e-10**，`allclose` 通过。

最大差异在 $10^{-9}$ 量级。这里的分母是 $n-1$（贝塞尔校正），所以公式里出现了 $n/(n-1)$。如果前向用 $n$ 做分母，反向也要相应改变——**前向和反向必须使用同一套约定**，这是手写梯度最容易出错的地方之一。

## 6.6 不用 autograd 训练

现在把整套手写反向传播用到完整训练上。网络与第 5 章基本相同：10 维嵌入、200 个隐藏神经元、BN、tanh、27 类输出；区别是保留了 `b1`（BN 之后其实多余，但留着可以顺便验证它的梯度），参数量为 **12297**。

区别在于：训练循环里没有 `loss.backward()`，梯度全部来自 Listing 6.3 与 6.5 的公式。

```python
# Listing 6.6 完全手写梯度的训练循环
torch.manual_seed(42)
n_hidden = 200
g = torch.Generator().manual_seed(2147483647)

C = torch.randn((27, 10), generator=g)
W1 = torch.randn((30, n_hidden), generator=g) * (5/3) / (30 ** 0.5)
b1 = torch.randn(n_hidden, generator=g) * 0.1
W2 = torch.randn((n_hidden, 27), generator=g) * 0.1
b2 = torch.randn(27, generator=g) * 0.1
bngain = torch.randn((1, n_hidden)) * 0.1 + 1.0
bnbias = torch.randn((1, n_hidden)) * 0.1

parameters = [C, W1, b1, W2, b2, bngain, bnbias]
for p in parameters:
    p.requires_grad = True

batch_size = n = 32
with torch.no_grad():
    for i in range(50000):

        ix = torch.randint(0, Xtr.shape[0], (batch_size,))
        Xb, Yb = Xtr[ix], Ytr[ix]

        # 前向
        emb = C[Xb]
        embcat = emb.view(emb.shape[0], -1)
        hprebn = embcat @ W1 + b1
        bnmean = hprebn.mean(0, keepdim=True)
        bnvar = hprebn.var(0, keepdim=True, unbiased=True)
        bnvar_inv = (bnvar + 1e-5)**-0.5
        bnraw = (hprebn - bnmean) * bnvar_inv
        hpreact = bngain * bnraw + bnbias
        h = torch.tanh(hpreact)
        logits = h @ W2 + b2
        loss = F.cross_entropy(logits, Yb)

        # 反向：全部手写
        dlogits = F.softmax(logits, 1)
        dlogits[range(n), Yb] -= 1
        dlogits /= n

        dh = dlogits @ W2.T
        dW2 = h.T @ dlogits
        db2 = dlogits.sum(0)

        dhpreact = (1.0 - h**2) * dh

        dbngain = (bnraw * dhpreact).sum(0, keepdim=True)
        dbnbias = dhpreact.sum(0, keepdim=True)
        dhprebn = bngain * bnvar_inv / n * (
            n * dhpreact
            - dhpreact.sum(0)
            - n/(n-1) * bnraw * (dhpreact * bnraw).sum(0)
        )

        dembcat = dhprebn @ W1.T
        dW1 = embcat.T @ dhprebn
        db1 = dhprebn.sum(0)

        demb = dembcat.view(emb.shape)
        dC = torch.zeros_like(C)
        for k in range(Xb.shape[0]):
            for j in range(Xb.shape[1]):
                dC[Xb[k, j]] += demb[k, j]

        grads = [dC, dW1, db1, dW2, db2, dbngain, dbnbias]

        # 更新
        lr = 0.1
        for p, grad in zip(parameters, grads):
            p.data += -lr * grad
```

注意最外层的 `with torch.no_grad():`：既然梯度全部手算，就不需要 PyTorch 建图，关掉 autograd 可以省下不少内存和时间。

用这个模型采样：

```python
# Listing 6.8 从手写训练的模型采样
g = torch.Generator().manual_seed(2147483647 + 10)
for _ in range(20):
    out, context = [], [0] * block_size
    while True:
        emb = C[torch.tensor([context])]
        embcat = emb.view(1, -1)
        hpreact = embcat @ W1 + b1
        hpreact = bngain * (hpreact - bnmean) * (bnvar + 1e-5)**-0.5 + bnbias
        h = torch.tanh(hpreact)
        logits = h @ W2 + b2
        probs = F.softmax(logits, dim=1)
        ix = torch.multinomial(probs, 1, generator=g).item()
        context = context[1:] + [ix]
        out.append(ix)
        if ix == 0:
            break
    print(''.join(itos[i] for i in out))
```

## 6.7 本章摘要

+ 把前向传播拆成原子变量，才能逐段验证反向传播；`torch.allclose` 是比较手写梯度与 autograd 的标准工具。
+ 反向传播只需三条规则：局部导数乘以传回的梯度；同一变量被多次使用时梯度累加；矩阵乘法的梯度用转置配对。
+ 手写 softmax + 交叉熵需要十几步，但合并后有闭式解：`∂L/∂logits = (softmax - onehot) / n`。
+ 手写 BatchNorm 的反向需要同时考虑直接路径、均值路径和方差路径，公式中会出现 $n/(n-1)$ 的贝塞尔校正因子。
+ 嵌入层的反向是散射累加：`dC[Xb[k,j]] += demb[k,j]`，同一个字符出现多次时要相加。
+ 完全不用 `loss.backward()`，只靠手写梯度也能训练出与 autograd 相同水平的模型。
+ 前向和反向必须使用同一套约定（例如方差除以 $n$ 还是 $n-1$），否则梯度会出现系统性偏差。
