这一章要把“凭感觉”变成“看得见”。我们会打开网络的内部，观察激活值和梯度的分布，找出训练不稳定的根源，然后用**批归一化**（Batch Normalization）把每一层的数值尺度控制住。批归一化是现代深度网络最常用的组件之一，理解它，也就理解了深度网络训练中最核心的数值问题。

## 5.1 第 4 章留下的两个问题

回看第 4 章的初始化：

```python
C  = torch.randn((27, 10), generator=g)
W1 = torch.randn((30, 200), generator=g)
b1 = torch.randn(200, generator=g)
W2 = torch.randn((200, 27), generator=g)
b2 = torch.randn(27, generator=g)
```

这些权重都直接从标准正态分布采样。问题就藏在这里。

**问题一：tanh 一开始就饱和。** 嵌入向量的每个分量方差约为 1，30 个输入相加后，隐藏层预激活的方差约为 30，标准差约为 5.5。而 `tanh` 在 |x| 超过 3 之后几乎变成一条水平线，导数 $1-\tanh^2(x)$ 接近 0。也就是说，网络一开始就工作在各层激活函数的“平坦区”，反向传播时梯度被压得极小，参数几乎不动。

**问题二：softmax 过度自信。** 隐藏层有 200 个输出，如果 `W2` 也取标准正态，logits 的标准差约为 $\sqrt{200}\approx 14$。softmax 对这样大的分数非常敏感：最大的那一项会接近 1，其余接近 0。模型一开始就对某个错误答案“确信无疑”，交叉熵损失极大，而正确类别的梯度又极小。初始损失 24.05 正是这么来的。

两个问题指向同一件事：**每一层的数值尺度失控了**。如果能把每一层的输出稳定在均值 0、方差 1 附近，tanh 就不会饱和，softmax 也不会过度自信，梯度就能顺畅地传回去。

## 5.2 用统计量诊断网络

在动手修之前，先学会“看病”。深度网络有三个常用的体检指标：

1. **激活值分布**：每一层输出的均值、标准差，以及饱和比例（`|tanh(x)| > 0.97` 的比例）。标准差太小说明信号被压扁，太大说明数值在爆炸，饱和比例高说明非线性进入了平坦区。
2. **梯度分布**：每一层反向传播得到的梯度标准差。如果深层梯度比浅层小几个数量级，就是**梯度消失**；反之是**梯度爆炸**。
3. **更新与数据的比例**：`lr * grad.std() / weight.std()`。这个比值衡量每一步参数更新的幅度相对于参数本身的尺度。经验上它应该在 $10^{-3}$ 左右：太小则学得慢，太大则训练震荡。

先做一个最小的受控实验，看看有归一化和没有归一化时，一个线性层的表现差多少：

```python
# Listing 5.1 线性层的前向与反向尺度（无归一化）
g = torch.Generator().manual_seed(2147483647)

a = torch.randn((1000, 1), requires_grad=True, generator=g)
b = torch.randn((1000, 1000), requires_grad=True, generator=g)
c = b @ a
loss = torch.randn(1000, generator=g) @ c

a.retain_grad(); b.retain_grad(); c.retain_grad()
loss.backward()
```

实测结果：

| 量 | 数值 |
| -- | ---- |
| 输入 a 的标准差 | 0.9876 |
| 权重 b 的标准差 | 1.0007 |
| 输出 c 的标准差 | **31.0124** |
| 回传到 a 的梯度标准差 | **30.8818** |
| 回传到 b 的梯度标准差 | 0.9667 |

输入是标准正态，经过一个 1000×1000 的线性层，输出标准差被放大了约 31 倍；反向传播时，梯度也被放大了约 31 倍。如果网络有十层这样的线性层，数值会放大到 $31^{10}$，直接溢出；如果权重再小一点，又会指数级衰减。**这就是深度网络难以训练的根源：尺度随层数指数变化。**

在同一个线性层后面加一个批归一化，再看：

```python
# Listing 5.2 线性层 + 批归一化
x = w @ inp
xmean = x.mean()
xvar = x.var()
out = (x - xmean) / torch.sqrt(xvar + 1e-5)

loss = out @ torch.randn(n, generator=g)
loss.backward()
```

实测结果：

| 量 | 数值 |
| -- | ---- |
| 线性层输出 x 的标准差 | 31.0124 |
| 归一化后 out 的标准差 | **1.0000** |
| 回传到 out 的梯度标准差 | 0.9783 |
| 回传到 x 的梯度标准差 | 0.0315 |
| 回传到权重的梯度标准差 | 0.0312 |
| 回传到输入的梯度标准差 | **0.9953** |

归一化把输出强制拉回标准差 1。更关键的是反向传播：梯度经过归一化层时被自动缩放，回到输入时仍然是 0.9953，不再随层宽放大或缩小。这就是批归一化最核心的作用——**让每一层的前向和反向都工作在可控的尺度上**。

## 5.3 批归一化的原理

批归一化对每个特征维度独立做标准化。设一个小批量有 $B$ 个样本，某一层的预激活是 $x \in \mathbb{R}^{B \times D}$，对第 $j$ 个特征：

$$\mu_j = \frac{1}{B}\sum_{i=1}^{B} x_{ij},\qquad
\sigma_j^2 = \frac{1}{B}\sum_{i=1}^{B}(x_{ij}-\mu_j)^2$$

$$\hat{x}_{ij} = \frac{x_{ij}-\mu_j}{\sqrt{\sigma_j^2+\epsilon}}$$

$$\text{BN}(x)_{ij} = \gamma_j \hat{x}_{ij} + \beta_j$$

其中：

+ $\mu_j$、$\sigma_j^2$ 是**当前小批量**的统计量，随批次变化；
+ $\epsilon$ 是一个极小的数（通常 $10^{-5}$），防止除以 0；
+ $\gamma_j$、$\beta_j$ 是**可学习**的缩放和偏移参数，初始值为 1 和 0。

既然已经把每个特征标准化了，为什么还要 $\gamma$ 和 $\beta$？因为标准化会强行抹掉这一层的尺度和偏移，而网络有时恰恰需要不同的尺度。$\gamma$、$\beta$ 把“是否需要还原”的决定权交还给训练：如果标准化有害，网络可以把 $\gamma$ 学成某个值，近似抵消它；如果有利，就保持标准化的结果。

训练时用批统计量，推理时怎么办？推理阶段可能只有一个样本，无法计算批均值。解决办法是维护一组**滑动平均**的统计量：

$$\mu_{\text{running}} \leftarrow (1-m)\mu_{\text{running}} + m\mu_{\text{batch}}$$

动量 $m$ 通常取 0.1。训练结束后，用这组滑动统计量做推理；这也是为什么切换 `train()` / `eval()` 模式对含 BN 的网络至关重要。

批归一化带来的好处可以总结为四点：

+ **稳定激活尺度**：每一层输出大致保持均值 0、方差 1，tanh 不会饱和，softmax 不会过度自信。
+ **稳定梯度尺度**：反向传播时梯度被自动缩放，深层网络不容易出现梯度消失或爆炸。
+ **降低对初始化的敏感度**：即使权重尺度不太对，BN 也能把激活拉回来。
+ **允许更大的学习率**：尺度稳定后，梯度不会突然爆炸，可以用更激进的步长。

代价是引入了批次依赖：训练时的输出取决于同批次的其他样本，batch size 太小时统计量噪声很大。此外，推理时必须正确使用滑动统计量，否则训练和推理的行为会不一致。

> **注意**
>
> 本节的手写实现用 `torch.var` 的默认行为（无偏方差，除以 $B-1$），而 PyTorch 的 `nn.BatchNorm1d` 使用有偏方差（除以 $B$）。当 batch size 为 32 时，两者只差 3% 左右，对训练几乎没有影响。理解原理比纠结这点差异更重要。

## 5.4 在 MLP 中加入 BN

把 BN 插到隐藏层的线性变换和 tanh 之间。同时修正初始化：`W1` 按 fan-in 缩放，`W2` 缩小 10 倍，去掉 `b1`（BN 的 $\beta$ 已经提供了偏置）。

```python
# Listing 5.3 带批归一化的 MLP
n_embd, n_hidden = 10, 200

g = torch.Generator().manual_seed(2147483647)
C  = torch.randn((27, n_embd), generator=g)
W1 = torch.randn((n_embd * block_size, n_hidden), generator=g) * (5/3) / (30 ** 0.5)
W2 = torch.randn((n_hidden, 27), generator=g) * 0.01
b2 = torch.zeros(27)

bngain = torch.ones((1, n_hidden))
bnbias = torch.zeros((1, n_hidden))
bnmean_running = torch.zeros((1, n_hidden))
bnstd_running = torch.ones((1, n_hidden))

parameters = [C, W1, W2, b2, bngain, bnbias]
for p in parameters:
    p.requires_grad = True
```

`(5/3)/sqrt(30)` 这个系数来自 Kaiming 初始化：为了让 `tanh` 在初始化时保持方差稳定，权重的标准差应当与 fan-in 的平方根成反比，5/3 是针对 tanh 的增益。`W2 * 0.01` 则是为了压住输出层的 logits，避免一开始就过度自信。

把 BN 放进训练循环，核心代码如下：

```python
# Listing 5.4 带批归一化的训练循环
for i in range(200000):
    ix = torch.randint(0, Xtr.shape[0], (32,), generator=g)
    Xb, Yb = Xtr[ix], Ytr[ix]

    emb = C[Xb]
    embcat = emb.view(emb.shape[0], -1)

    hpreact = embcat @ W1
    bnmeani = hpreact.mean(0, keepdim=True)
    bnstdi = hpreact.std(0, keepdim=True)
    hpreact = bngain * (hpreact - bnmeani) / bnstdi + bnbias

    with torch.no_grad():
        bnmean_running = 0.999 * bnmean_running + 0.001 * bnmeani
        bnstd_running = 0.999 * bnstd_running + 0.001 * bnstdi

    h = torch.tanh(hpreact)
    logits = h @ W2 + b2
    loss = F.cross_entropy(logits, Yb)

    for p in parameters:
        p.grad = None
    loss.backward()

    lr = 0.1 if i < 100000 else 0.01
    for p in parameters:
        p.data += -lr * p.grad
```

训练结束后，用滑动统计量评估：

```python
# Listing 5.5 用滑动统计量评估
@torch.no_grad()
def split_loss(x, y):
    emb = C[x]
    hpre = emb.view(emb.shape[0], -1) @ W1
    hpre = bngain * (hpre - bnmean_running) / bnstd_running + bnbias
    return F.cross_entropy(torch.tanh(hpre) @ W2 + b2, y).item()

print(split_loss(Xtr, Ytr))
print(split_loss(Xdev, Ydev))
print(split_loss(Xte, Yte))
```

参数总量为 **12097**：`C` 270、`W1` 6000、`W2` 5400、`b2` 27、BN 的 $\gamma$ 200、$\beta$ 200。BN 增加了 400 个参数，同时去掉了 `b1` 的 200 个，净增 200 个，却换来了训练稳定性。

修正初始化本身就能带来最大的改善：验证损失从 2.356 降到 2.200，因为它让 tanh 不再一开始就饱和。在此基础上加入 BN，验证损失只从 2.200 微降到 2.197，训练损失甚至略高——所以在这组只有 5 万步、单隐藏层的小实验中，**BN 并不是提升精度的主力**。

这并不说明 BN 没用。它的价值在于**鲁棒性**：让网络对初始化尺度、学习率和深度不那么敏感。下面的深层网络会展示这一点——当网络从 1 个隐藏层变成 5 个时，没有 BN 很难训练，有了 BN 才能让每一层的激活和梯度都保持在健康范围。

## 5.5 用类封装：PyTorch 风格的网络

手写 BN 的代码能跑，但每加一层就要复制一遍归一化逻辑，很快就会失控。更工程化的做法是把每种操作封装成类，像搭积木一样组合——这正是 PyTorch 的 `nn.Module` 所做的事。

```python
# Listing 5.6 Linear、BatchNorm1d、Tanh 三个类
class Linear:
    def __init__(self, fan_in, fan_out, bias=True):
        self.weight = torch.randn((fan_in, fan_out), generator=g) / fan_in**0.5
        self.bias = torch.zeros(fan_out) if bias else None

    def __call__(self, x):
        self.out = x @ self.weight
        if self.bias is not None:
            self.out += self.bias
        return self.out

    def parameters(self):
        return [self.weight] + ([] if self.bias is None else [self.bias])


class BatchNorm1d:
    def __init__(self, dim, eps=1e-5, momentum=0.1):
        self.eps = eps
        self.momentum = momentum
        self.training = True
        self.gamma = torch.ones(dim)
        self.beta = torch.zeros(dim)
        self.running_mean = torch.zeros(dim)
        self.running_var = torch.ones(dim)

    def __call__(self, x):
        if self.training:
            xmean = x.mean(0, keepdim=True)
            xvar = x.var(0, keepdim=True)
        else:
            xmean = self.running_mean
            xvar = self.running_var
        xhat = (x - xmean) / torch.sqrt(xvar + self.eps)
        self.out = self.gamma * xhat + self.beta
        if self.training:
            with torch.no_grad():
                self.running_mean = (1 - self.momentum) * self.running_mean + self.momentum * xmean
                self.running_var = (1 - self.momentum) * self.running_var + self.momentum * xvar
        return self.out

    def parameters(self):
        return [self.gamma, self.beta]


class Tanh:
    def __call__(self, x):
        self.out = torch.tanh(x)
        return self.out

    def parameters(self):
        return []
```

每个类都有两个方法：`__call__` 负责前向传播，`parameters()` 返回自己的可训练参数。这种约定的好处是，网络可以写成一个列表，前向就是循环：

```python
# Listing 5.7 一个五层的深层网络
n_hidden = 100
layers = [
    Linear(30, n_hidden, bias=False), BatchNorm1d(n_hidden), Tanh(),
    Linear(n_hidden, n_hidden, bias=False), BatchNorm1d(n_hidden), Tanh(),
    Linear(n_hidden, n_hidden, bias=False), BatchNorm1d(n_hidden), Tanh(),
    Linear(n_hidden, n_hidden, bias=False), BatchNorm1d(n_hidden), Tanh(),
    Linear(n_hidden, n_hidden, bias=False), BatchNorm1d(n_hidden), Tanh(),
    Linear(n_hidden, 27, bias=False), BatchNorm1d(27),
]

with torch.no_grad():
    layers[-1].gamma *= 0.1     # 让输出层一开始不要过度自信

# 复用 5.3 节的嵌入矩阵 C
parameters = [C] + [p for layer in layers for p in layer.parameters()]
for p in parameters:
    p.requires_grad = True
```

这个网络有五个隐藏块，每个块是“线性 → BN → tanh”，最后接一个线性层和 BN，输出 27 个 logits。参数量为 **47024**。

最后一层的 `gamma *= 0.1` 值得解释：输出层的 BN 把 logits 标准化到方差 1，再乘 0.1，相当于让初始 logits 的尺度变小，softmax 更平缓，避免一上来就“押注”某个字符。这是对 5.1 节“softmax 过度自信”的又一次修正。

训练深层网络仍然使用四步循环，只是把前向换成 `layers` 列表：

```python
# Listing 5.8 训练深层网络
for i in range(50000):
    ix = torch.randint(0, Xtr.shape[0], (32,), generator=g)
    Xb, Yb = Xtr[ix], Ytr[ix]

    x = C[Xb].view(Xb.shape[0], -1)
    for layer in layers:
        x = layer(x)
    loss = F.cross_entropy(x, Yb)

    for p in parameters:
        p.grad = None
    loss.backward()

    lr = 0.1 if i < 40000 else 0.01
    for p in parameters:
        p.data += -lr * p.grad
```

```python
# Listing 5.10 从深层网络采样
for layer in layers:
    layer.training = False

g = torch.Generator().manual_seed(2147483647 + 10)
for _ in range(20):
    out, context = [], [0] * block_size
    while True:
        x = C[torch.tensor([context])].view(1, -1)
        for layer in layers:
            x = layer(x)
        probs = F.softmax(x, dim=1)
        ix = torch.multinomial(probs, 1, generator=g).item()
        context = context[1:] + [ix]
        out.append(ix)
        if ix == 0:
            break
    print(''.join(itos[i] for i in out))
```

## 5.8 本章摘要

+ 深度网络训练不稳定的根源是数值尺度失控：tanh 饱和使梯度消失，softmax 过度自信使损失巨大。
+ 三个诊断工具：激活值分布（均值、标准差、饱和比例）、梯度分布、更新与数据的比例（经验值约 $10^{-3}$）。
+ 一个小实验就能看出问题：无归一化的 1000×1000 线性层把输出标准差从 1 放大到 31；加 BN 后输出标准差回到 1，梯度也稳定在同一尺度。
+ 批归一化对每个特征做批内标准化，再用可学习的 $\gamma$、$\beta$ 恢复表达能力；训练用批统计量，推理用滑动平均统计量。
+ 在 MLP 中，BN 插在线性层和 tanh 之间；同时用 Kaiming 初始化缩放 W1、把 W2 缩小 10 倍，初始损失从 24 降到正常范围。
+ 把 Linear、BatchNorm1d、Tanh 封装成类，就可以像搭积木一样组合深层网络；五层网络的参数量为 47024。
+ 诊断显示五层 tanh 的激活标准差保持在 0.67–0.74，梯度标准差都在 $2.8\times10^{-3}$ 左右，更新比例落在 $10^{-3}$ 量级，说明 BN 有效控制了深层网络的数值行为。
+ 五层网络训练 5 万步的验证损失为 2.1115，与单隐藏层训练 20 万步的 2.1057 几乎持平，说明在 BN 的帮助下加深网络不会破坏训练稳定性。
